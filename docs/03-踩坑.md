# 三、踩坑清单 —— 每一个都真踩过

> 按「代价」排序。第 1、2、3 条造成过**线上卡片实际损坏**。

---

## 1. `col.db.execute()` 不提交 —— 静默丢数据 ⭐⭐⭐

**现象**：脚本打印「回填 88 张」，复查时一张都没改。

**根因**：`col.db` 是 `DBProxy`，**没有 `commit()` 方法**。`col.close()` 也不替你提交。
手写 `col.db.execute("update …")` 的改动会全部丢失，而且**不报错**。

**正确做法**：

```python
# ✅ 官方 API（推荐）
n = col.get_note(nid)
n["自测"] = "自测"
col.update_note(n)          # 自动提交 + 标 usn + 重生成卡片

# ✅ 或者（op 是一个函数，不是 with 上下文！）
col.db.transact(lambda: col.db.execute("update …"))

# ❌ 这些都不行
col.db.commit()                       # AttributeError: 没有这个属性
with col.db.transact():               # TypeError: 少参数 op
    col.db.execute("update …")
```

**代价**：第一次部署 v7 时 88 张「观点」的 `自测` 全丢，多跑了一轮才补上。

## 2. CSS 变量只向下继承 —— 令牌挂错位置整张卡失去底色 ⭐⭐⭐

**现象**：卡片掉在白底上，`--desk` 桌面色完全不生效。

**根因**：CSS 自定义属性**只向下继承**。`.card`（Anki 容器）是 `.pg`（卡片本体）的
**祖先**，令牌挂在 `.pg` 上，`.card` 读 `--desk` 就是 undefined → `background-color` 失效。

**演变**：
- 旧版（24 套）挂 `.card` ✅
- v6.0 误挂 `.pg` ❌（我写的）
- v6.1 起改挂 `:root` ✅（比 `.card` 更安全，`body` 也读得到）

**顺带的**：每套版式各自的桌面色怎么铺满视口？

```css
.pg { box-shadow: …, 0 0 0 100vmax var(--desk); }
```

最后一层扩散阴影从卡片向外铺满。**不用 `:has()`**（老客户端不支持），
也**不能靠 `.card` 背景色**（读不到每套各自的 `--desk`）。

## 3. 模板根类和 CSS 不匹配 —— 370 张卡变白板 ⭐⭐⭐

**现象**：CSS 里有 24 套版式，卡片却完全没有样式。

**根因**：模板输出 `class="ex type-{{类型}}"`，而 CSS 写的是 `.pg.skin-xxx`。
**零条 `.ex-*` 规则** → 全部裸奔。

**这是外部污染**（前一位 agent 把模板换成了自己的 `.ex` 结构），
而我回滚时**只还原了 CSS，没还原模板** → 白板状态持续了一天半才被发现。

**规矩**：

> **改 CSS 之前，先确认模板到底在输出什么 class。**
> 每次部署完跑一遍「模板用得到 / CSS 有没有」的覆盖核对表
> （`anki-deploy/inspect_css.py` 就是这个用途）。
>
> 回滚 CSS 时，**模板也要一起回滚**。

## 4. 失效的「风格」值 —— 257 张卡是白卡 ⭐⭐

**现象**：4 套版式部署好了，但 370 张里 257 张还是白卡。

**根因**：这些卡的「风格」字段还写着**旧 24 套的名字** ——
`poster / moon / receipt / menu / blueprint / broadside / bamboo` ——
新 CSS 里没有对应类。

**实测**：

| 类型 | 有效版式 | 失效（白卡） |
|---|---|---:|
| 句子 | paper 77 | poster 76 + moon 31 = **107** |
| 方法 | 0 | receipt 42 + menu 40 + blueprint 16 = **98** |
| 观点 | paper 36 | broadside 38 + bamboo 14 = **52** |

**规矩**：换版式池之后，必须跑一次「失效风格重分配」
（`anki-deploy/fix_styles.py`，按 SKILL.md 的类型→版式池轮换）。
**只动失效的**，已经是有效值的不要动 —— 用户看到的版式不该被无谓换掉。

## 5. 装饰件必须「显式关掉」，不是「不写」

模板里这些元素**一直存在**：`.tape` `.stamp` `.seal` `.wave` `.mark`。
CSS 里没有规则 ≠ 不显示 —— 它们会以浏览器默认样式**裸奔**。

特别是 `.stamp` 和 `.seal` **各吐一遍「类型」文本**，答案面上会出现两遍。

```css
.pg .tape, .pg .stamp, .pg .seal, .pg .wave { display: none; }
.pg .mark { display: none; }
```

`.mode-read`（通读卡）再按需打开：

```css
.mode-read .mark { display: block; }   /* 大引号 */
.mode-read .wave { display: block; }   /* 分隔波浪 */
```

## 6. 不写 `.card` 容器重置，桌面端和移动端会长得不一样 ⭐⭐

Anki 各端会在 `.card` 上注入自己的样式：

```css
.card { text-align: center; background-color: #fff; padding: 0; }
```

不压掉的话，同一张卡在不同端差很远。必须：

```css
.card {
  text-align: left !important;
  background-color: var(--desk) !important;
}
.card > * { box-sizing: border-box; }
body { margin: 0; padding: 0; }
```

## 7. 长文 HTML 排版 ——「方法」类是整篇文章，不是纯文本 ⭐⭐

**实测**：98 张「方法」卡，正文中位 **1142 字**，最长 **13302 字**，
内容是带 `<p> <ul> <li> <table> <strong> <a>` 的完整 HTML。

`base.css` 原来只有 `.body p` 一条 → 表格溢出、列表缩进吃掉版心、`<strong>` 变粗黑块。

必须补全套，其中：

```css
.pg .body a { word-break: break-all; }   /* b 站搜索 URL 不断行会撑破版心 */
.pg .body table { width: 100%; border-collapse: collapse; }
```

**数据污染**（另一件事，未处理）：部分「我的话」字段塞进了完整的
`<meta charset> / <title> / <style>` 网页源码 —— 复制粘贴带进来的。

## 8. syncserver 常驻占锁 —— 读同步副本必须三文件快照

`anki-syncserver` 一直开着，锁着同步副本。直接打开报
`DBError: Anki already open`，连 `sqlite3 ?mode=ro` 都报 `database is locked (5)`。

**读**：把 `.anki2` + `-wal` + `-shm` **三个文件一起** cp 到别处再打开。
少一个都可能读到半截状态。

**写**：先 `systemctl stop anki-syncserver`，改完 `chown hermes:hermes`，再 start。

## 9. 装完模板 ≠ 手机看得到

必须刷 `notetypes.mtime_secs` 和 `usn`，否则同步服务认为模型没变，不推给设备：

```python
now = int(time.time())
col.db.transact(lambda: (
    [col.db.execute(f"update notetypes set mtime_secs={now}, usn=-1 where name=?", n)
     for n in ("生活摘录", "生活挖空", "生活选择")],
    col.db.execute(f"update col set mod={now * 1000}"),
))
```

## 10. `choice.css` / `cloze.css` 依赖 base 里没定义的令牌 ⭐

`choice.css` 用了 `--fs-3` `--lh-3` `--w-2`；
`cloze.css` 用了 `--w-2`。

`base.css` 的尺度里如果只有 `--fs-1/2/body/5`，这些就是 undefined，
边框宽度会掉回 `medium`（3px），字号会掉回默认 —— **不报错，只是长得不对**。

## 11. 同一 python 进程不能连开两个 Collection

报 `Anki already open`。要对比两个库（比如工作库 vs 备份），**分进程跑**，
或者先 `col.close()` 再开下一个。

## 12. heredoc 里的中文 / f-string 会被 zsh 当 glob

**现象**：`no matches found`，脚本没推上去。

**做法**：复杂的 python 一律**写文件再推**：

```bash
zsh .ssh/push-finance.sh local/script.py /tmp/script.py
./.ssh/ssh-finance.sh "sudo $PY /tmp/script.py"
```

`push-finance.sh` 走 stdin + `sudo tee`，不经过 shell 展开。

## 13. SSH 走本地 HTTP 代理，端口每次会话都变

本机所有出网走本地 HTTP 代理，SSH 必须经 CONNECT 隧道。
代理端口每次会话变（实测 61149 → 55048 → …），`scutil --proxy` 读不到。

**`.ssh/find_proxy.py` 自带兜底**：先验证环境变量里的代理能不能开隧道，
不行就 `lsof -nP -iTCP -sTCP:LISTEN` 扫端口现探测。
**脚本里必须自带兜底，不能假设环境变量一定在。**

连接失败的头号现象：

```
SSH proxy transport: ValueError
Connection closed by UNKNOWN port 65535
exit=255
```

## 14. 小坑合集

| 坑 | 说明 |
|---|---|
| 正则 `skin-[a-z]+` | 会把 `skin-` 前缀也捕获，导致 24 套全被判「多余」。用 `skin-([a-z]+)` |
| 挖空 `ord` 超出模板数 | 不是异常。cloze 只有 1 个模板，但按 c1/c2/c3 生成多张卡，`ord=0/1/2` 都合法 |
| 参数传大 int | `col.db.execute(sql, bigint)` 有时不灵，拼进 SQL 更稳 |
| `cards` 表没有 `mid` 列 | 要 `join notes` 才能按笔记类型统计 |
| 统计家目录要带隐藏项 | `du -sh ~/.[!.]* ~/*`，只写 `~/*` 会漏掉约 22 GB |
| 本机 `rm` 是包装器 | 删不掉东西还返回 0。要写 `/bin/rm`（仍可能被沙箱静默拒绝） |

## 15. headless Chrome 渲染出来的卡面会"白"——别误判

**症状**：用 Playwright + Chromium 截图自检时，某几张卡整张是桌面色，看不到文字和边框。
但**结构审计全过**（HTML 里 `.pg skin-xxx`、`.title`、`.body` 都在）。

**根因**：`skin-gezhi` / `skin-memo` 用了 `"Songti SC", "Source Serif SC", "Noto Serif CJK SC"` 等中文字体。
headless Chromium 跑在 macOS 沙箱里**没装这些字体** → 衬线 fallback 退化 → 文字宽度过窄。
`skin-kaiwu` 用无衬线（macOS 自带），所以它渲染正常。

**这不是数据/CSS bug，是渲染环境 bug。** Anki 桌面端/移动端字库不一样，真机上正常。

**自检时**：
- 结构审计（HTML 含 `.pg` / 无 `{{` / skin 有效）够了，**别靠截图判断**
- 想截图，**只截 kaiwu 风格的卡**做代表
