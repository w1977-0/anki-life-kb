## 一、项目研判

| 项 | 实测 |
|---|---|
| 性质 | **awesome 列表**（生活技巧集合），非书稿 |
| 规模 | 20 个主题文件 / **H2=73 · H3=38** / 3.7 万字符 / 16 个外链 |
| **语言** | **纯英文**（中文字符 0） |
| **许可** | **无 LICENSE 文件** ⚠️ 默认版权保留 |
| 结构 | `# 主题` + `## 技巧标题` + 说明（可含 `### 子技巧`） |
| 内容风格 | **第一人称个人经验叙述**（"When COVID hit, most stores…"） |

### 与前 5 个项目的差异

| | 前 5 个 | **本项目** |
|---|---|---|
| 语言 | 中文 | **纯英文** |
| 体裁 | 书稿 / 条目体 / 循证 | **个人经验随笔** |
| 规模 | 608 / 387 / 390 / 36 / 34 | **111（73+38）** |
| 许可 | Unlicense / CC BY-NC | **无 LICENSE** |

**必须让你知道的三点**：
1. **无许可文件** → 个人自用制卡属合理使用，但**不要公开分发**
2. **英文内容** → 若不翻译，卡片对中文使用者价值有限
3. **个人经验** → 不像《高性价比人生指南》有期刊来源，**不能当硬知识**

## 三、技术要点

| 项 | 处理 |
|---|---|
| 切分 | `^## ` 和 `^### ` 都切；H3 归属其父 H2 |
| 正文 | 英文原文 → HTML（段落/列表/链接） |
| 外链 | 16 个，保留可点（英文原文的引用） |
| 内部链接 | `./Productivity.md` 等 → 转纯文字（Anki 里点不动，前一轮踩过） |
| 空文件 | `OneWheel.md`/`Plants.md` 无 H2 → 跳过或整篇一张 |
| 长度 | 多数很短（1-3 句），不需截断 |

## 四、质控红线

| 规则 | 理由 |
|---|---|
| **卡片必须标注来源 + 无许可提示** | 无 LICENSE，须尊重出处 |
| 不删原文、不改写 | 与前 5 个项目一致 |
| 英文原文不得机器翻译后当"原文" | 翻译会失真，宁可不翻 |
| 入库前查重 | 与现有 6940 张比对 |
| 入库后跑媒体双向核对 | 前一轮的坑 |

## 五、已知的坑（从前面项目带过来）

1. **新建牌组前必须先 `decks --all` 核实编号**（本轮 up 项目踩过：20.11 被占）
2. **批量导入脚本必须幂等**（SSH 重试会导致重复导入）
3. `media.db` 的 `csum` 是 `hashlib.sha1(d).digest()`（20 字节 BLOB）
4. 改 media 前停 syncserver；改完跑 `anki_media_check.py` 看两行都是 0
5. `grep` 中文会被 zsh 吃掉 → 用 Python 搜
6. `scp` 后单独核 MD5 再部署
7. 读 sqlite 快照要连 `-wal`/`-shm`

## 六、执行结果（2026-09-27 完成，v2 中文版）

**用户拍板的三件事**：① 语言用**中文翻译**；② **不用自测**，每段一张通读卡；③ 风格**统一 kaiwu 不轮换**。

| 项 | 结果 |
|---|---|
| 脚本 | `alh2cards.py` v2 重写：中文翻译表内嵌（缺一条翻译即报错）；日期=2026年9月26日；类型=方法（引言=句子、Plants=感悟）；自测=空；出处=中文（英文原名） |
| 张数 | **103**（= 旧版 93 小节 + 补回 8 张引言卡 + OneWheel/Plants 整篇 2 张） |

| 媒体 | OneWheel 姿势图 SVG 入 media + media.db 注册；`anki_media_check.py` 两行 **0** |
| 同步 | fix_sync_state 后工作库=副本：notes **7044** / cards **10232**；usn 干净 |

**修正上一任 v1 的五类问题**（接手时核查发现）：
1. 多 H1 文件（Eating 有 Eating/Dieting/Drinking 三节）的引言被粘进上一张卡正文（Baklava、Water Supplement 卡被污染）
2. JavaScript 代码块被错误渲染成 `` `<code>javascript …</code>` ``；v2 增加代码围栏处理
3. 7 张卡的出处残留原始 markdown 链接语法
4. H1 引言段与 OneWheel/Plants 两整篇被静默丢弃（违背「正文全量」）
5. 「类型=观点 + 自测=空」互相矛盾、日期全空、风格未按体系轮换
