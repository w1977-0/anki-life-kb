## 一、项目研判

| 项 | 实测 |
|---|---|
| 性质 | **微习惯配方集合**（非书稿、非文章） |
| 文件 | 17 个 md（15 个分类 + 完整索引 + 100个奖励方式） |
| **规模** | **微习惯配方 300 条** + 奖励方式 108 条 → 制卡 **404 张** |
| 语言 | 中文 |
| 许可 | **MIT**（与前面 CC BY-NC / 无 LICENSE 的项目都不同，最宽松） |

### 内容格式（天然的问答对）

```
## 工作环境设置 (1-6)
1. 在我踏入办公室的门之后，我会把手机调成静音模式，并把它放到包里。
```

**「在【触发】之后，我会【行为】」** —— 这本身就是问答对：
- 触发 = 问题（正面问句）
- 行为 = 答案（背面）

### ⭐ 数据完整性：300 是怎么核出来的（关键过程）

项目名叫"300个微习惯"，但**机械统计一直对不上**，逐步收敛：

| 统计方式 | 结果 | 问题 |
|---|---:|---|
| 所有 `数字.` 列表项 | 422 | 把"常见错误""使用原则"等非配方项算进去了 |
| 只算含「之后，我会」 | 291 | 漏了「后 / 时」触发词的变体（9 条） |
| 触发词放宽为「之后\|后\|时」 | 299 | 漏了用「**我将**」而非「我会」的那 1 条 |
| 复杂单行正则（再放宽） | 275 | **正则回溯导致失配**，反而更差 |
| ✅ **行级判断**（逐行看，不用大正则） | **300** | — |

**教训：复杂正则在长文本上会因回溯失配，统计必须用行级判断。**
（关键：现在脚本 `mh2cards.py` 用的就是行级判断。）

另外，触发词/行为词都有变体，过滤器必须覆盖：
- 触发：`之后` / `后` / `时`
- 行为：`我会` / `我将` / `会` / `将`

## 二、卡片形态与牌组

### 归属判定

用体系的判定句问：*"这张卡，我是要练会它，还是用到时查它，还是留个纪念？"*

微习惯 = **要练会的行为**（建立"触发→行为"的自动化联结）
→ 归 **`10：在练`**（不是前面那些项目的 `20：在用`）

### 牌组

```
10：在练::10.09：微习惯配方
├── 10.09.01：职场相关    100   （职场女性/新晋管理者/团队工作/提高效率/保持专注）
├── 10.09.02：健康生活     60   （改善睡眠/减轻压力/大脑健康）
├── 10.09.03：人生阶段     60   （大学生/老人/照顾者）
├── 10.09.04：居家办公     20
├── 10.09.05：人际关系     20
├── 10.09.06：习惯改变     20
├── 10.09.07：特定场景     20   （出差）
└── 10.09.08：奖励方式    104
                        合计 404
```

编号核实：`10.01`~`10.08` 已占用 → **`10.09` 可用**（新建前已 `decks` 核实，避开了上次 20.11 撞车的坑）。

### 两类卡

| | 微习惯配方（300） | 奖励方式（104） |
|---|---|---|
| 类型 | `概念` → **回忆型**（自测=自测） | `句子` → 通读型 |
| 正面 | 在【触发】之后，我会做什么？ | 奖励方式本身 |
| 背面 | 【行为】 | 同左（通读卡） |
| 理由 | 有天然问答结构，该背下来形成自动化 | 没有触发-行为结构，查即可 |

**问句合格性**：正面只写触发、不写行为，**不泄露答案**。
验收：300 条全部以"…我会做什么？"结尾，**0 条不符**。

## 四、本轮新踩的坑（补充到既有清单）

既有清单见 `docs/14` 第六节，本轮新增：

11. **统计不要用复杂单行正则**——长文本上会回溯失配（299→275 反而更差）。
    改用**逐行判断**（`re.match` + 两个 `re.search`）。
12. **触发词/行为词都有变体**——「之后/后/时」「我会/我将/会/将」都必须覆盖，
    否则会漏条（本次漏了 9+1 条才发现）。
13. **"100个奖励方式.md" 前面有「使用原则」**（4 条非奖励项），
    必须跳过到 `## 🎉 100个奖励方式` 之后才收，否则把原则当条目。
14. **查询牌组别用 `like '%10.09%'`**——会误匹配做饭指南的 `20.10.09：半成品`。
    要用牌组名特征（如 `%微习惯配方%`），或注意 DB 里分隔符是 `\x1f` 不是 `::`。
15. **服务器 `/tmp` 是 tmpfs，重启后文件丢失**——脚本每次要重新 `scp` 上传，
    不要假设上次传的还在。
