# 07 · 自建 Anki 同步服务器

官方的 AnkiWeb 同步在国内经常很慢。自建一个，数据在自己服务器上，
手机、电脑、网页端随时同步，速度取决于你的服务器而不是 AnkiWeb。

> 想一键完成就跑 `deploy/01-deploy-syncserver.sh`。
> 这份文档讲**每一步在做什么**，方便你排查和改造。

---

## 一、原理

Anki 官方在 `anki` 这个 Python 包里**内置了同步服务器**（`anki.syncserver`）。
不需要额外装东西，起一个进程就行。

```
┌──────────────┐         ┌─────────────────────┐         ┌──────────────┐
│  Anki 客户端  │  HTTPS  │  反向代理（HTTPS）    │  HTTP   │  syncserver  │
│  手机 / 电脑  │ ──────▶ │ anki.example.com    │ ──────▶ │ 127.0.0.1    │
└──────────────┘         └─────────────────────┘         │    :8080     │
                                                          └──────┬───────┘
                                                                 │
                                                          /var/lib/anki-autocards/
                                                            sync/anki/collection.anki2
```

**关键：syncserver 只听 `127.0.0.1`，不直接暴露到公网。**
HTTPS 和鉴权交给反向代理（Cloudflare Tunnel / Caddy / nginx）。

---

## 二、目录与账号

| 路径 | 用途 |
|---|---|
| `/opt/anki-autocards/venv` | 独立 Python 环境（不碰系统 Python） |
| `/opt/anki-autocards/anki_cli.py` | 制卡命令行工具 |
| `/etc/anki-autocards/config.json` | CLI 配置（`0640`，服务账号可读） |
| `/etc/anki-autocards/syncserver.env` | 同步服务器凭据（`0600`） |
| `/var/lib/anki-autocards/collection.anki2` | **工作库**（CLI 直接读写它） |
| `/var/lib/anki-autocards/sync/anki/` | **同步副本**（syncserver 用这份） |
| `/var/lib/anki-autocards/backups/` | 每次写入前的自动备份，留 20 份 |

> **两套库要分清**：工作库是 CLI 写的地方，同步副本是 syncserver 服务客户端的地方。
> 每次 `anki sync` 会把工作库推到同步副本。别直接编辑同步副本。

## 三、第一步：venv 与依赖

```bash
sudo apt-get update
sudo apt-get install -y python3-venv python3-pip   # Debian 13 必须装 python3-venv

sudo mkdir -p /opt/anki-autocards
sudo python3 -m venv /opt/anki-autocards/venv
sudo /opt/anki-autocards/venv/bin/pip install --quiet --upgrade pip
sudo /opt/anki-autocards/venv/bin/pip install --quiet anki
```

**坑**：Debian 13 自带的 Python 3.13 默认**没有 `ensurepip`**，
光验证 `import venv` 成功没用，真正决定能不能建 venv 的是 ensurepip。
所以先 `apt install python3-venv`，别等到第 2 步才炸。

验证：

```bash
/opt/anki-autocards/venv/bin/python -c "import anki; print(anki.__version__)"
# 期望 26.9.2 或类似
```

---

## 四、第二步：服务账号

```bash
sudo useradd --system --home-dir /var/lib/anki-autocards \
             --shell /usr/sbin/nologin ankiuser || true
sudo mkdir -p /var/lib/anki-autocards/{sync,backups}
sudo chown -R ankiuser:ankiuser /var/lib/anki-autocards
```

---

## 五、第三步：凭据与环境

```bash
sudo mkdir -p /etc/anki-autocards

# 密码要"能被人手打" —— 排除 0 O o 1 I l i S 5 这些形近字符
SYNC_PASS=$(/opt/anki-autocards/venv/bin/python -c \
  "import secrets; a='abcdefghjkmnpqrstuvwxyz2346789'; print(''.join(secrets.choice(a) for _ in range(16)))")

sudo tee /etc/anki-autocards/syncserver.env >/dev/null <<EOF
SYNC_USER1=anki:${SYNC_PASS}
SYNC_BASE=/var/lib/anki-autocards/sync
SYNC_HOST=127.0.0.1
SYNC_PORT=8080
EOF
sudo chmod 0600 /etc/anki-autocards/syncserver.env
```

> **为什么密码要排除形近字符**：实测踩过 —— 32 位随机串里有 `1/I`、`0/O`，
> 用户手输连试 4 次全被 403 拒绝。同步地址是在手机上敲的，**必须能被人手打**。

CLI 配置：

```bash
sudo tee /etc/anki-autocards/config.json >/dev/null <<EOF
{
  "endpoint": "http://127.0.0.1:8080/",
  "username": "anki",
  "password": "${SYNC_PASS}",
  "collection": "/var/lib/anki-autocards/collection.anki2",
  "backup_dir": "/var/lib/anki-autocards/backups",
  "lock_file": "/var/lib/anki-autocards/.anki-cli.lock",
  "backup_keep": 20
}
EOF
sudo chmod 0640 /etc/anki-autocards/config.json
sudo chown root:ankiuser /etc/anki-autocards/config.json
```

`0640` + `root:ankiuser` 是关键 —— **密码不能被其他用户读到**，
但要让运行 Agent 的服务账号能读。

## 六、第四步：systemd 单元

```ini
# /etc/systemd/system/anki-syncserver.service
[Unit]
Description=Anki self-hosted sync server
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=ankiuser
Group=ankiuser
EnvironmentFile=/etc/anki-autocards/syncserver.env
ExecStart=/opt/anki-autocards/venv/bin/python -m anki.syncserver
Restart=on-failure
RestartSec=5

# 小内存机器必加
MemoryMax=220M
MemoryHigh=180M

# 加固
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=strict
ProtectHome=read-only
ReadWritePaths=/var/lib/anki-autocards
ProtectKernelTunables=true
ProtectControlGroups=true
RestrictSUIDSGID=true

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now anki-syncserver
sudo systemctl status anki-syncserver
```

验证（**应返回 200**）：

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:8080/
```

> 浏览器打开 `https://anki.example.com/` 会看到 **404，那是正常的**。
> 同步接口没有网页界面。想看状态就部署 `deploy/02-status-page.sh`。

## 七、第五步：反向代理（HTTPS）

三种方案选一个：

### A. Cloudflare Tunnel（推荐，不用开防火墙端口）

```
Cloudflare Dashboard → Zero Trust → Networks → Tunnels
  Public Hostname: anki.example.com
  Service:         http://127.0.0.1:8080
  ⚠️ 不要加 Access 策略 —— Anki 客户端不会走浏览器登录
```

### B. Caddy（自动 HTTPS）

```caddyfile
anki.example.com {
    reverse_proxy 127.0.0.1:8080
}
```

### C. nginx

```nginx
server {
    listen 443 ssl;
    server_name anki.example.com;
    ssl_certificate     /path/to/fullchain.pem;
    ssl_certificate_key /path/to/privkey.pem;
    client_max_body_size 200m;      # 全量上传可能很大
    location / { proxy_pass http://127.0.0.1:8080; }
}
```

> `client_max_body_size` 别忘 —— 首次全量同步会传整个 collection，
> 默认 1m 会直接 413。

## 八、第六步：设备接入

在 Anki（桌面 / 手机）里：

| 项 | 填什么 |
|---|---|
| 同步地址 | `https://anki.example.com/` |
| 用户名 | `anki` |
| 密码 | syncserver.env 里那个 |

**首次迁移**（把现有卡片搬到自建服务器）：

1. 先在**官方 AnkiWeb** 同步一次，确保官方服务器上是最新
2. 改同步地址为自建服务器
3. Anki 会提示方向 —— 选 **Upload**（上传到自建服务器）
4. 之后就都在自建服务器上同步了

> ⚠️ **方向选错会清空数据。** 本项目的 `anki_cli.py` 内置护栏：
> 检测到需要 `FULL_UPLOAD` 时会抛 `SafetyError` 直接中止，
> 防止服务器端空库反向覆盖客户端。看到这个报错别绕过，它是保护你的。

## 九、状态页（可选）

同步接口没有网页界面，想知道它还活着，可以起一个只读状态页：

```bash
sudo bash deploy/02-status-page.sh
```

它会：

- 建 `anki-status.example.com` 的 systemd 服务（另一个端口）
- 页面显示：同步服务器是否响应、collection 笔记数、最近修改时间、磁盘占用

**这条路由与同步链路完全隔离** —— 状态页挂了不影响同步。

## 十、排障

| 症状 | 检查 |
|---|---|
| 客户端 403 | 密码抄错了（形近字符）；`SYNC_USER1` 格式是 `user:pass` |
| 客户端超时 | 反向代理没通；`curl http://127.0.0.1:8080/` 看是不是 200 |
| 413 Request Too Large | nginx/Caddy 的 body size 限制 |
| 服务器有、手机没有 | 手机上**手动同步一次** |
| `FULL_UPLOAD` 护栏触发 | 别绕过，按提示处理 |
| 同步副本读不到 | syncserver 常驻占锁；读之前要**三文件快照**（`.anki2` + `-wal` + `-shm`） |

---

## 十一、安全清单

- [ ] `syncserver.env` 权限 `0600`，属主 `root`
- [ ] `config.json` 权限 `0640`，属主 `root:ankiuser`
- [ ] syncserver 只绑 `127.0.0.1`
- [ ] 反向代理**不加** Access / Basic Auth（Anki 客户端过不去）
- [ ] 备份目录定期清理（`backup_keep: 20`）
- [ ] 不要把这些文件提交进 Git
