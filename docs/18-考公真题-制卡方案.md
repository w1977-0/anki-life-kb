## 一、项目研判

| 项 | 实测 |
|---|---|
| 性质 | **Obsidian 库**：2016–2026 国考/省考/联考行测真题，**按考点重组** |
| 规模 | **22,375 篇笔记** / 11,282 题 / 21,829 张图 / 64,891 处链接 |
| 模块 | **资料分析 3,569** + **判断推理 7,713** |
| 每题结构 | frontmatter（qid/试卷/地区/年份/考点）+ **问法模型/推理链/最快解法/易错点/母题抽象** + 题干/选项/解析/材料 |
| 图片 | 公式图 17,000（67MB）+ 题目图 4,829（197MB）= **263MB** |

### 为什么这批内容**不能**用「生活摘录」

| | 生活摘录（前面 7 个项目） | **考公真题** |
|---|---|---|
| 性质 | 读的东西 | **要做的题** |
| 用户动作 | 通读 | **先做，再看答案** |
| 核心价值 | 正文全量 | **推理链 / 最快解法 / 易错点** |
| 形态 | 单面通读 | **选择题（正面题、背面答案+解法）** |

**结论：必须新建专用笔记类型。** 套用通读模板 = 把"做题"变成"读题"，废掉一半价值。

## 二、笔记类型设计：`考公真题`

### 字段（13 个）

| # | 字段 | 来源 | 说明 |
|---|---|---|---|
| 1 | `题干` | `### 题干` | 题目 |
| 2 | `选项` | `### 选项` | A/B/C/D，正确项带 ✅ |
| 3 | `答案` | 选项里的 ✅ 提取 | 如 `D` |
| 4 | `材料` | `### 给定材料` | 资料分析的材料（含图表） |
| 5 | `推理链` | `## 推理链` | **怎么一步步想出来** |
| 6 | `最快解法` | `**最快解法**` | ⚡ 秒杀技巧 |
| 7 | `易错点` | `## 易错点` | ⚠ 防坑 |
| 8 | `母题抽象` | `## 母题抽象` | 🧩 举一反三 |
| 9 | `解析` | `### 官方解析` | 官方解法（对照用） |
| 10 | `考点` | frontmatter | 便于筛选 |
| 11 | `试卷` | frontmatter | 来源（含地区年份） |
| 12 | `风格` | 脚本轮换 | 体系字段 |
| 13 | `日期` | 脚本填 | 体系字段 |

### 模板设计（核心）

**正面 —— 只给"做题需要的东西"**：
```
考点标签 · 试卷
─────────────────
[材料]（可折叠，资料分析必看）
题干
A. …
B. …
C. …
D. …
```

**背面 —— 正面内容 + 学习区**：
```
（同正面，但正确项高亮）
═══════════════════
✅ 答案：D
⚡ 最快解法        ← 最醒目（你的学习风格是"答案优先"）
🔗 推理链          ← 完整推导
⚠ 易错点          ← 防坑
🧩 母题抽象        ← 举一反三
📄 官方解析        ← 对照
```

### CSS 设计要点

| 项 | 做法 | 理由 |
|---|---|---|
| 选项 | 每条独立成行、加大行距 | 手机上点选不误触 |
| 正确项 | 底色 + 左边框 + 加粗 | 一眼看到，不用找 ✅ |
| 学习区块 | 每块有标题条 + 淡底色 | 五种信息不混成一坨 |
| 最快解法 | 排在最前、底色最重 | 你要的是"下次怎么秒杀" |
| 材料 | `<details>` 折叠 | 材料长，不折叠会淹没题干 |
| 公式图 | `max-width:100%`、垂直居中 | 公式图大小不一 |
| 字号 | 题干 17px、解析 15px、标签 12px | 层级分明 |

### 卡片形态（本次的核心）

**正面**：考点标签 + 试卷 + 材料（折叠）+ 题干 + 选项（**不高亮**）
**背面**：同上 + **✅ 答案** + **⚡ 最快解法**（最醒目）+ 🔗 推理链 + ⚠ 易错点 + 🧩 母题抽象 + 📄 官方解析

**为什么这样设计**：
- 你的学习风格是「**答案优先**」→ 背面把「最快解法」排在最前、底色最重
- 「易错点」用警示色、「母题抽象」用蓝色 → 五种信息一眼分得开
- 正确项用**绿底 + 左边框 + 加粗**，不用找 ✅ 符号
- 材料用 `<details>` 折叠 → 资料分析的材料很长，不折叠会淹没题干
- **正面绝不出现 ✅**（自检专验这一条）

### 执行中的一个插曲

复制 7302 张图时 **SSH 断连**，`syncserver` 停在 inactive。重连后确认：
图片已复制完（14,991 个）、media.db 已注册（7,302）、卡片已导入（+1300）——
**脚本实际跑完了**，只是断在"重启 syncserver"那一步。手动恢复后一切正常。
**教训：长任务要拆步，别把"停服务"和"重启服务"放在同一个长脚本里。**

## 八、分类修正（2026-09-29，用户指出）

### 我上一批的错误

把 1300 题**全塞进「行测」一个牌组**，只靠标签区分考点 —— **层级压平了**。

### 项目自己的分类（研究后确认）

```
行测（顶层）
├── 判断推理 ── 图形推理 / 定义判断 / 科学推理 / 类比推理 / 逻辑判断
└── 资料分析 ── 增长 / 比重 / 综合 / 平均数 / 其他 / 倍数 / 基期计算
```

**第三级「考点」不能做牌组**：光「增长」子类下就有 **1,167 个不同考点**（1300 题），
最多的「增长量比较」才 25 题，还有噪声（如 `(1+r)）` 是解析残留）。
→ **考点只做标签**（`考点-增长量比较`）。

### 修正后的牌组结构

```
10：在练::10.02：考试::10.02.01：行测
├── （本级）26 张 ← 原有旧卡，未动
├── 资料分析
│   ├── 增长           1,300 ✅
│   ├── 比重             840（已生成待导入）
│   ├── 综合             668
│   ├── 平均数            319
│   ├── 其他             273
│   ├── 倍数             168
│   └── 基期计算（增长类）     1
└── 判断推理
    ├── 逻辑判断        2,475
    ├── 图形推理        1,880
    ├── 类比推理        1,630
    ├── 定义判断        1,598
    └── 科学推理          130
```

**脚本已改**：`--cat "资料分析/比重"` → 自动落到 `…::行测::资料分析::比重`。
**预建**：其余 13 个子类牌组已建好（空着没关系，结构先立住）。

旧牌组「行测」下有 **1,326 张**，其中：

### ⭐ 本批踩的坑（4 个，都很贵）

| # | 坑 | 代价 | 正解 |
|---|---|---|---|
| 20 | 服务器 **`/tmp` 只有 483MB tmpfs** | scp 传 174MB 包直接失败 | 大文件传 `/home/<SSH用户>/`（`/var/lib/anki-autocards` 是 `750 hermes`，<SSH用户> 进不去） |
| 21 | **Python 循环复制 14,524 张图** | 跑 **1 小时 8 分**没完，还把本地 shell 执行环境搞坏（`echo` 都 137，需重启应用） | **shell `tar` + `cp`**：同样的事 **4 分钟** |
| 22 | **长任务没用 `nohup`** | SSH 断连 → 脚本被杀 → 图片复制完但**注册和导入没跑**，白等 20 分钟 | `nohup ... &` 脱离 SSH |
| 23 | **`pgrep -f kg2_install` 会匹配自己的查询命令** | 误判"脚本还在跑"，实际早死了，白等 15 分钟 | 查进程用 `pgrep -af` 看**完整命令行**，或看日志/输出文件 |

**教训（已入长期记忆）**：
1. 服务器 `/tmp` 483MB，**任何 >100MB 的文件都不放 /tmp**
2. **批量文件操作用 shell，不用 Python 循环**（快 15 倍以上）
3. **所有可能超 2 分钟的远程任务一律 `nohup`**
4. **停/启服务必须分步**，不能和长任务放一个脚本
