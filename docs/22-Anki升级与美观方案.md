## 二、升级项（按优先级）

### A. 恢复 863 张 buried 卡（复习治理，收益最大）
影响：非归档 863 张卡重新进入复习队列（历史批量导入时被埋，用户从没见过它们）。
做法：一键脚本把所有非归档 buried 卡置回 queue=0，或分批（每批 200）避免当日复习爆量。
验证：手机上该区卡数增加；`cards.queue=-1` 非归档数归零。
回滚：备份 collection 后操作，可再埋回。

### B. 每日新卡上限（让队列转起来）
影响：新卡 2,638 vs 待复习 264（≈8:1），复习永远追不上新卡。给各区 deck options
设每日新卡上限（建议 10：在练 10 张、20：在用 20 张、30：读过 10 张/天），复习优先。
做法：deck options 批量设置（手机端或我出脚本）。
验证：连续一周复习负载平稳、每天新卡按上限进入。
回滚：改回原设置即可。

### C. 夜间模式（美观，低风险高收益）
影响：四套版式全部。base.css 已全面用 CSS 变量（--ink/--accent/--paper…），
只缺 `@media (prefers-color-scheme: dark)` 的变量覆盖段。加一段即可全局夜间化。
做法：改 `/opt/anki-autocards/docs/css/base.css` + deploy 脚本写入 collection。
验证：手机切夜间模式看任何一张卡。
回滚：`base.css.bak-*` 现存备份 + 部署脚本回滚。

### D. 长文卡阅读体验（16.5K 字的 171 卡在手机上太长）
影响：44+ 张长文卡。方案二选一：① afmt 加"回顶"浮动按钮；② 把 `<h3>` 小节做成
`<details>` 折叠，默认展开第一个 Part。倾向②（阅读定位价值大）。
做法：改长文模板 + CSS 一段。
验证：手机打开 171 卡可折叠导航。
回滚：模板备份 + deploy 回滚。
