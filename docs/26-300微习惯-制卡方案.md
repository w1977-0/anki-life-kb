## 二、设计决策（每条都对着体系判定句与既有规则走）

| 决策 | 取值 | 理由 |
|---|---|---|
| 牌组 | `20：在用::20.15：微习惯配方`（编号待服务端核实后定稿） | 判定句：配方是「做事时翻出来照着做」→ 20 在用，同 20.14 生活技巧先例；不是 10 在练（无考试式掌握标准） |
| 子牌组 | 15 分类 + 1 奖励方式，共 16 个（20.15.01–16） | 分类本身就是这个仓库的价值，做子牌组比 flat+tags 好导航 |
| 类型 | 全部「方法」（通读） | 配方=可操作步骤；**不做回忆型**：回忆正面只露出处，分类名当出处则正面无触发线索（正是 G3 闸要拦的形态）；把触发问句塞出处则违反 P1。真回忆版需模板加「问题」字段，另案提 |
| 出处 | 分类名（如「保持专注」「奖励方式」） | 真来源（项目内分类），>3 字不触发 G3 |
| 来源字段 | 《300个微习惯配方》· 子标题（如「工作环境设置」） | 保留原文小节归属，alh 惯例 |
| tags | 微习惯配方 / 类-分类 / 组-子标题 | 主题词化，无类型词 |
| 版式/日期/自测 | 全部留空由脚本推导 | 硬闸要求，不手工指定 |
| evidence | 每条正文前 24 字原文 | 脚本逐字闸（归一化后必须命中） |
| 目录卡 | 1 张（16 分类 + 每类条数 + 一句话说明），出处=目录 | 体验标准第 7 条：一批 >5 张必须带 |
