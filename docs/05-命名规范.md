# 五、命名规范 · 编号、名字、emoji、评级

> 版本：v1.0　|　2026-09-20　|　配套 `04-分类体系.md`

**一句话**：`<编号>：<名字><状态符><评级>`

```
30：读过                                  ← 区
30.01：书                                 ← 类
30.01.02：《影响力》✨✨✨✨✨🌟            ← 目（来源层，带评级）
```

---

## 1. 编号

| 层 | 格式 | 例 | 说明 |
|---|---|---|---|
| 区 | `NN` | `30` | 顶层。预留号 `30/40/50/…/80` 空着 |
| 类 | `NN.NN` | `30.01` | 每区 **≤10 个**（Johnny Decimal 的铁律） |
| 目 | `NN.NN.NN` | `30.01.01` | 具体来源（一本书、一个专栏） |
| 分册 | 不再编号 | `第一册词汇` | 同一来源下的卷/册/季，直接写名字 |

### 三条硬规则

**① 编号永不回收。**
删掉的分类，编号**留空**，不复用。
`30.02` 拆走了，`30.02` 就永远是空的 —— 十年后翻旧记录还能对上。

**② 名字随便改，编号不动。**
这是把编号和名字分开的全部意义。觉得"在用"不顺口改成"常用"，随便。
编号 `20` 不动，Hermes 和你的肌肉记忆都还在原位。

**③ 一位数补零。**
`30.01` 不是 `30.1`。Anki 按字符串排序，`30.1` 会排在 `30.10` 前面乱掉。

---

## 2. 名字

| 规则 | 对 | 错 |
|---|---|---|
| 编号与名字之间用**全角冒号 `：`** | `30.01：书` | `30.01:书` / `30.01 书` |
| 层级分隔符是 `::`（Anki 原生），前后**不加空格** | `30：读过::30.01：书` | `30：读过 :: 30.01：书` |
| 分类名 **2–6 个汉字**，动词性或名词性 | `在练` `网络碎片` | `我平常会反复看的一些东西` |
| 来源名用**书名号** | `《纳瓦尔宝典》` | `纳瓦尔宝典` |
| 不在名字里塞空格 | `《邓小平时代》` | `《邓小平时代》 —— 傅高义` |

### 现存的三个错误写法（迁移时一并修掉）

| 现状 | 问题 | 修正 |
|---|---|---|
| `008:宜人性交流的词汇变换` | 半角冒号 | `20.02.01：情绪词汇` |
| `003：微信读书零散笔记💗` | "零散笔记"是分类失败的自白 | `30.01：书` |
| `002：单篇文章::一句话` | "一句话"描述的是**形状**不是**来源** | `30.05：网络碎片` |

**"一句话"为什么错**：形状是内容属性，归 `类型` 字段管。
牌组要写**来源** —— 它其实是 B 站评论、微博、贴梗，所以叫"网络碎片"。

## 3. 状态符（emoji，保留并系统化）

**用在哪**：区层、类层。可选，最多一个，贴在名字**后面**。

| 符 | 含义 | 什么时候贴 |
|---|---|---|
| 💗 | **心头好** | 你最在意、会主动翻的（沿用你原来的 `…提炼💗` `…执行💗`） |
| 🔥 | **正在攻坚** | 这段时间集中练的 |
| 🧊 | **冷却中** | 暂时不看，但别删 |
| 📌 | **常翻** | 每周都会用到 |
| ✅ | **已掌握** | 练成了，只剩维持 |

```
10：在练🔥          这段时间主攻
20：在用💗          心头好，常翻
30：读过            无标记 = 常态
```

**💗 的来历**：你原来就把它贴在 `C：文章保存并提炼💗` 和 `B：反复、再反复执行💗` 上 ——
意思是"这两个我很在意"。**这个直觉是对的，现在写成了规则。**

---

## 4. 评级（✨ / 🌟，保留并提升）

**用在哪**：只用于**来源层** —— `30.01：书` / `30.03：课程` / `30.04：影像` 的第三层。
贴在最后，**状态符之后**（两者一般不共存，状态符在区/类，评级在目）。

| 评级 | 含义 |
|---|---|
| ✨ | 留档而已 |
| ✨✨ | 还行 |
| ✨✨✨ | 好 |
| ✨✨✨✨ | 很好，会推荐给别人 |
| ✨✨✨✨✨ | 极好，会重读 |
| **＋🌟** | **附加标记：改变了我**（叠在任意星级后，不占星位） |
| 不标 | 未评级 |

### 你原来的两本书，正好落在这个体系里

```
《影响力》✨✨✨✨✨🌟   →  5 星 ＋ 改变了我
《领导力》✨✨✨✨✨🌟   →  5 星 ＋ 改变了我
```

**保留原样，一个字没动。** 是这套规范从你的习惯里长出来的，不是我编的。

### 🌟 为什么单独存在

星级是**评价**，🌟 是**影响**。
一本 3 星的书可能恰好在某件事上改变了你 —— 那就是 `✨✨✨🌟`。
两者正交，所以 🌟 不占星位、可以叠在任何星级后面。
