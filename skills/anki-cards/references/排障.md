# 出错了怎么办

脚本报错时读这份。它会告诉你出了什么事，这份告诉你**下一步**。

## 先跑一次自检

```bash
ANKI="/opt/anki-autocards/venv/bin/python /opt/anki-autocards/anki_cli.py --config /etc/anki-autocards/config.json"
$ANKI selftest
```

四项全 `true` 才正常：collection 可打开 / 同步服务器可达 / 同步方向安全 / anki 库版本。

## 常见错误 → 下一步

| 提示 | 意思 | 下一步 |
|---|---|---|
| `类型「X」不在九个值里` | 判错了 | 读 `类型与版式.md`，按六问重判 |
| `牌组「X」不存在` | 名字写错，或真要新建 | 用现有牌组；或加 `--create-deck`（新书时才用） |
| `版式「X」无效` | 拼错了 | 只能 `kaiwu` / `gezhi` / `paper` / `memo` |
| `被查重拦下` | 这句话库里已经有了 | **告诉用户"这句之前记过"，不要重试**。查重是全库短语搜索，使用说明里的示例句也会命中 |
| `写入失败：缺少字段…` | 极少见，工具会自动补 | 看返回的 `repairs`，如实告诉用户 |
| `SAFETY_ABORT` | 检测到 FULL_UPLOAD | **停下，不要绕过**。这是保护用户卡片不被覆盖的机制，如实转述 |

## ⚠️ 绝不允许的三件事

1. **不许绕过 FULL_UPLOAD 护栏** —— 不改配置、不直接调 anki 库、不换命令重试
2. **不许动 `/etc/anki-autocards/config.json`、不许 pip install、不许直接改 collection 文件**
3. **不许改 CSS / 模板 / 加字段 / 迁移删除牌组** —— 这些要先问用户

## 同步

写卡会自动同步（写入前一次、写入后一次）。
用户手机上没看到 → 让他**在 Anki 里手动同步一次**。

`required` 的含义：`0`不用动 / `1`普通同步 / `2`全量同步 / `3`全量下载 / **`4`全量上传（危险，会被护栏拦下）**。
