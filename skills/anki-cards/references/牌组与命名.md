# 牌组体系与命名

只在**定牌组**或**新建牌组**时才读这份。

## 六个顶层（顺序 = 活跃度，越往下复习越少）

| 编号 | 名字 | 放什么 |
|---|---|---|
| `00：系统` | 系统 | 使用说明 / 收件箱 / 待改写 |
| `10：在练` | 在练 | 要靠重复长到身上的：语言 考试 专业 创作 身体 生活技能 心智 数字 |
| `20：在用` | 在用 | 已经会了，做事时翻出来用：工作 沟通 财务 健康 关系 事务 决策 工具 |
| `30：读过` | 读过 | 别人的素材：书 文章 课程 影像 网络碎片 典籍 |
| `40：记过` | 记过 | 我自己的：事件 里程碑 感悟 人 地方 决定 |
| `90：归档` | 归档 | 外语（整批导入）/ 冷却 / 模板 / 废卡 |

## 判定顺序

1. **用户说了放哪** → 照办
2. **先看出处**：知乎 → `30.02：文章::30.02.01：知乎`（已有）；书 → `30.01：书`；
   B站/微博/评论区 → `30.05：网络碎片`；我的想法 → `40.03：感悟`；应考 → `10.02：考试`
   **同一个出处只进一个牌组** —— 别让知乎的内容分在两个地方

## 整篇保留（`--whole`）该进哪

| 内容 | 牌组 |
|---|---|
| 别人的文章 / 长文（知乎、公众号…） | `30：读过::30.02：文章::30.02.01：知乎` |
| 一本书的一章 | `30：读过::30.01：书::<编号>：《书名》` |
| 我自己的长文 / 想法 | `40：记过::40.03：感悟` |

⚠️ 容易搞错的两个：
`30.03：课程` 是**课程/讲座**（不是文章）；
`40.05：地方` 是**去过的地方**（不是我的文章）。
拿不准就 `decks --all`，别凭字面猜。
3. **判断不了** → `00：系统::00.02：收件箱`，**不要猜**

**10 在练 还是 20 在用？** 问一句：*"我要练到不用想就能做出来吗？"* 是 → 在练；不是 → 在用。

## 编号（三条硬规则）

| 层 | 格式 | 例 |
|---|---|---|
| 顶层 | `NN` | `30` |
| 二级 | `NN.NN` | `30.01` |
| 三级 | `NN.NN.NN` | `30.01.01` |
| 分册 | 不再编号 | `第一册词汇` |

1. **编号永不回收** —— 删掉的分类编号留空，不复用
2. **名字随便改，编号不动**
3. **一位数补零** —— `30.01` 不是 `30.1`（Anki 按字符串排序，不补零顺序会乱）

每区最多 10 个二级。不够就拆区。

## 写法

| 规则 | 对 | 错 |
|---|---|---|
| 编号后**全角冒号** | `30.01：书` | `30.01:书` |
| 层级 `::` 前后不加空格 | `30：读过::30.01：书` | `30：读过 :: 30.01：书` |
| 分类名 2–6 汉字 | `网络碎片` | `我平常看的那些零碎东西` |
| 来源用书名号 | `《纳瓦尔宝典》` | `纳瓦尔宝典` |

**写"来源"不写"形状"**：`网络碎片` 对，`一句话` 错 —— 形状归 `类型` 字段管。

## 状态符（贴在顶层或二级，最多一个）

💗 心头好 ／ 🔥 正在攻坚 ／ 🧊 冷却中 ／ 📌 常翻 ／ ✅ 已掌握

## 评级（只贴来源层：书 / 课程 / 影像）

| 评级 | 含义 |
|---|---|
| ✨ | 留档 |
| ✨✨ | 还行 |
| ✨✨✨ | 好 |
| ✨✨✨✨ | 很好，会推荐 |
| ✨✨✨✨✨ | 极好，会重读 |
| ＋🌟 | **附加**：改变了我。叠在任意星级后，**不占星位** |

**不要自己给书评级。** 用户没说就不标。
星级是"评价"，🌟 是"影响" —— 两者正交，3 星的书也可能改变你。

## 别做

- 不要给已有牌组改名，不要新建平行体系
- **牌组名写错不报错，会静默建出野牌组** —— 写之前先 `decks --all` 看一眼

## 出处不要加书名

卡片「出处」= `N. 标题`（**不嵌书名**）。

书名由牌组承载（牌组名用《》，如 `《纳瓦尔宝典》`、`《致爱自己的人（一）》`）。

**不要在出处里写 `《书名》· N. 标题` 这种重复前缀** ——
书名已经在牌组名里了，出处再写一遍是冗余，而且会让卡片标题过长。
