# Anki 制卡

把飞书里收到的一段内容，做成卡片，写入 Anki 并同步到用户设备。
**价值在"加工"这一段**，不在搬运。

开工先输出一行 `[已加载 Anki 制卡]` —— 既是给用户的反馈，也是提醒自己后面按流程走。

## 术语（全文统一，不要换说法）

| 用这个词 | 不要说 |
|---|---|
| 卡片 | 卡、条目、笔记 |
| 牌组 | 分类、目录、文件夹 |
| 类型 | 内容类型、种类 |
| 版式 | 皮肤、主题、样式 —— **字段名是** `风格` |
| 出处 | 来源、标题、书名 |
| 形式 | 只有两种：**通读** / **回忆** |

---

## When to Use

- 用户发来一段内容并表达了"记下来"的意思（说法见 description 的触发词）
- 用户问这套卡片体系的事：有哪些牌组、某张卡在哪、现在多少笔记

**Not for：**

- 只想讨论内容 → 直接对话，不写卡
- 要你解释 / 翻译 / 总结 → 不写卡
- 用户没要求制卡 → **不主动写**（写操作会进复习队列）

---

## Procedure

### 第 0 步 · 自检（只读，每次开工一次）

```bash
ANKI="/opt/anki-autocards/venv/bin/python /opt/anki-autocards/anki_cli.py --config /etc/anki-autocards/config.json"
$ANKI selftest
```

四项全 `true` 才继续。不对就停下报告用户，**不要自己想办法绕**。

### 第 1 步 · 判类型（中自由度）

**只判类型，别的都不用你管** —— 形式和版式脚本会推导。

拿不准 → **读** `references/类型与版式.md`（六问判定法 + 完整对照表）。

十个值：句子 / 典故 / 概念 / 观点 / 感悟 / 方法 / 场景 / 事件 / 里程碑 / **长文**

**`长文` 是给"整篇保留"用的**：形式是通读（自测留空），版式只用 paper，
**不受 150 字上限约束，也不拆**。判断标准：内容是一篇**完整的、有标题的文章**
（不是金句 / 观点 / 方法步骤），且用户要整篇保留 → 判 `长文` + 加 `--whole`。

判不准就先读 `references/类型与版式.md`

### 第 1.5 步 · 写出处（**必须是真来源**）

出处是卡片顶部的标题，**不能写占位符**。历史上 137 张卡的出处被填成了
牌组名「一句话」，显示出来毫无意义 —— 脚本现在会拦。

| 情况 | 出处写什么 |
|---|---|
| 书 | `《纳瓦尔宝典》` |
| 平台文章 | `知乎` / `B站` / `微博` |
| 课程、讲座 | 课程名 |
| **实在不知道来源** | `网络`（牌组配 `30.05：网络碎片`） |
| 我自己想的 | 触发它的场景或书，如 `读完《被讨厌的勇气》想到的` |

❌ 禁止：`一句话` / `未知` / `无` / `??` —— 会被脚本拦下。

### 第 2 步 · 定牌组（中自由度）

- 用户说了放哪 → 照办
- **先看出处**：出处写"知乎" → `30：读过::30.02：文章::30.02.01：知乎`（已有，别另起炉灶）
- 书摘 → `30：读过::30.01：书::<编号>：《书名》`
- 出处是 B站 / 微博 / 评论区 → `30：读过::30.05：网络碎片`
- 用户自己的想法 → `40：记过::40.03：感悟`
- **判不了 → `00：系统::00.02：收件箱`，不要猜**

**同一个出处只进一个牌组** —— 别让知乎的内容分在两个地方。
不确定就跑 `$ANKI decks --all`。新建牌组的编号规则在 `references/牌组与命名.md`。

### 第 3 步 · 写卡（**低自由度 —— 必须用脚本，不许手写 JSON**）

**不要先去搜索查重** —— 脚本会拦，撞上了照提示做就行。预先 `$ANKI search`
是白花一次工具调用。

**整篇保留（不加 `--whole` 默认会拆）**：
- 用户说"整篇 / 这篇文章 / 全文 / 别拆" → 加 `--whole`
- 加了之后：脚本**强制 paper 版式**（克制横格、版心放宽，最适合长文），
  自动加 `完整保留` 标签，**不拆、不拦 150 字上限**

**`--whole` 该进哪个牌组（别搞错类别）：**

| 内容 | 牌组 |
|---|---|
| 别人的文章 / 长文（知乎、公众号…） | `30：读过::30.02：文章::30.02.01：知乎`（已有，别另起炉灶） |
| 一本书的一章 | `30：读过::30.01：书::<编号>：《书名》` |
| 我自己的长文 / 想法 | `40：记过::40.03：感悟` |

⚠️ `30.03：课程` 是**课程/讲座**，`40.05：地方` 是**去过的地方** ——
**都不是文章，也都不是"我的文章"。先跑 `decks --all`，别凭字面猜。**

**长文必须用 `--body-file`，不能用 `--body`：**

```bash
# 先把正文写成 HTML 文件（<p> 分段、<h3> 小标题），再：
... --body-file /tmp/xxx.html
```

原因：命令行**单参数上限 128KB**，超过会 `OSError: Argument list too long`。
一篇长文轻易就超 —— 所以只要正文超过约 3 万字（或文件 >100KB），一律走 `--body-file`。

**正文分段**：用 `\n\n`（空行）分隔段落 —— 脚本会自动转成 `<p></p>`，
  `base.css` 的 `.body p` 规则会自动给段间距。**别只写 `\n`，HTML 会折叠成空格**。

**执行**（不是阅读）这个脚本：

```bash
/home/hermes/.hermes/skills/note-taking/anki-cards/scripts/anki_add.py \
  --deck "30：读过::30.01：书::30.01.01：《纳瓦尔宝典》" \
  --type 句子 \
  --body "欲望就是你跟自己的约定：在得到我想要的东西之前，我拒绝快乐。" \
  --source "《纳瓦尔宝典》" \
  --tags "读书,纳瓦尔宝典"
```

可选：`--note "我的评论"` / `--skin kaiwu` / `--create-deck`（新书才加） /
`--dry-run`（预演） / `--whole`（整篇保留）

脚本会自动做：补齐 7 个字段、由类型推 `自测`、按版式池轮换版式、**校验牌组是否存在**。

**脚本报错时照它给的提示做**，别自己另想办法，更别去翻文件系统。
看不懂就看 `references/排障.md`。

### 第 4 步 · 汇报

用自然语言，具体到能核对。必须包括：写了几张、放进哪个牌组、什么类型。

**出现下面任一情况，必须说出来：**

- `工具补了：…` → 少写了什么，如实说
- `被查重拦下` → 告诉用户"这句之前记过"，**不要重试**
- 任何 `failed` → 说原因，不要盲目重跑

最后一句：**"手机拉一下同步就能看到。"**

## Pitfalls

| 坑 | 后果 | 怎么避 |
|---|---|---|
| **手写 JSON** | 漏字段、版式拼错 | 用脚本，别手搓 |
| **牌组名写错** | **不报错，会静默建出野牌组** | 脚本会校验；拿不准用收件箱 |
| **示例句挡住真卡** | 查重是全库短语搜索，使用说明里的示例句也会命中 | 告诉用户"之前记过"，别重试 |
| **改写正文** | 原句措辞本身就是价值 | 保真，只删承接词、用 `……` 标省略 |
| **该藏的没藏** | 金句做成先藏后显 = 假测试 | 类型判准，脚本自动推形式 |
| 没说来源就瞎编 | 出处是卡片标题 | 用户没说 → 写场景，或**先问** |

## 别做多余动作（每次都省 token）

| 多余动作 | 为什么不用做 |
|---|---|
| 写卡前先 `$ANKI search` 查重 | 脚本会拦，撞上照提示做 |
| 每张卡写完跑一次 `stats` | 全部写完后跑一次就够 |
| 写卡后逐条 `search` 验证 | 脚本已返回牌组和笔记数 |

---

## Verification

**全部写完后跑一次**（不要每张卡跑一次）：

```bash
$ANKI stats
```

**笔记数应该正好 +N**（N = 你写进去的张数）。没加就是没写成，去看返回的 `failed` / `skipped`。

### 遇到意外就记一条

如果这次撞上了没预料到的事（被查重拦下、类型判错、牌组找不到……），
**用 `memory` 工具记一条**，写清"什么事 + 下次怎么办"。
官方把这个叫"让 agent 自己复盘" —— 记下来的比猜出来的准。

## 结构改动要问过用户（重要）

你的权限是无人确认直接执行，所以下面这些**不要自己动手**，
先说明要改什么、影响多少张卡，等用户点头：

改 CSS、改模板、加字段、迁移或删除牌组、动 `anki_cli.py`、动 Hermes 配置。

**写入卡片是正常的，不用问。**
